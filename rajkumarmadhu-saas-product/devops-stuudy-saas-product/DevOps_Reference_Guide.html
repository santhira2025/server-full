🌿 Git — Version Control
🔁
Daily Workflow
ESSENTIAL
  • git statusCheck what's changed
  • git add .Stage all changes
  • git commit -m "feat: add podcast endpoint"Commit with message
  • git push origin mainPush to remote
  • git pull origin mainPull latest changes
  • git log --oneline -10View last 10 commits
🌿
Branch Management
WORKFLOW
  • git checkout -b feature/ai-podcastCreate + switch to new branch
  • git branch -aList all branches
  • git merge feature/ai-podcastMerge feature into current
  • git branch -d feature/ai-podcastDelete merged branch
  • git stash && git stash popTemporarily hide changes
  • git rebase mainRebase onto main branch
🐳 Docker — Containerization
🏗️
Build & Run
  • docker build -t santhira .Build from Dockerfile
  • docker run -p 8001:8001 santhiraRun container
  • docker run -d --name santhira-api santhiraRun in background
  • docker psList running containers
  • docker logs -f santhira-apiFollow container logs
🧹
Manage & Clean
  • docker stop santhira-apiStop container gracefully
  • docker rm santhira-apiRemove container
  • docker rmi santhiraRemove image
  • docker system prune -afClean all unused resources
  • docker exec -it santhira-api bashShell into container
🐙
Docker Compose
  • docker compose up -dStart all services
  • docker compose downStop all services
  • docker compose logs -f apiFollow API service logs
  • docker compose build --no-cacheRebuild images fresh
  • docker compose psStatus of all services
☸️ Kubernetes — Orchestration
🔍
Inspect & Debug
kubectl
  • kubectl get pods -AAll pods in all namespaces
  • kubectl describe pod <pod-name>Full pod details + events
  • kubectl logs -f <pod-name>Stream pod logs
  • kubectl get events --sort-by=.lastTimestampRecent cluster events
  • kubectl exec -it <pod> -- /bin/shShell into pod
  • kubectl top podsCPU & Memory usage
🚀
Deploy & Scale
DEPLOY
  • kubectl apply -f deployment.yamlApply manifest file
  • kubectl rollout status deploy/santhiraCheck rollout progress
  • kubectl scale deploy/santhira --replicas=5Scale deployment
  • kubectl rollout undo deploy/santhira🔴 Rollback instantly
  • kubectl set image deploy/santhira api=santhira:v2Update container image
  • kubectl delete pod <pod> --forceForce terminate stuck pod

🔍 Common Error Quick Reference
Error Tool Severity Quick Fix
CrashLoopBackOff Kubernetes CRITICAL kubectl logs <pod> to see crash reason
OOMKilled Kubernetes CRITICAL Increase memory limits in yaml spec
ImagePullBackOff Kubernetes HIGH Check image name & registry credentials
502 Bad Gateway Nginx HIGH Upstream service is down or port mismatch
permission denied Linux / Docker MEDIUM chmod / chown or run with correct user
AccessDenied AWS HIGH Check IAM policy has correct permissions
